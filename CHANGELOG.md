# Changelog

All notable changes to EsyType are documented here. Format: Keep a Changelog. Versioning: SemVer.

## [Unreleased]

### Added
- 2026-11-22, Stage 5: **double-tap** the push-to-talk key for hands-free (and again to stop); **Undo Last Dictation** (⌃⌘Z or menu) that removes only the untouched dictated text, never sending ⌘Z; quitting mid-recording releases the microphone.
- 2026-11-22, Stage 4: **Text Cleanup** screen (sidebar ▸ Personalisation): switchable rules for filler words, repeated words, repeated phrases, punctuation and spacing, and sentence capitals, with a live preview. Links, emails, code, numbers and abbreviations are never changed. The filler switch moved here from Settings ▸ Speech.
- 2026-11-22, Stage 3: **Snippets** (sidebar ▸ Snippets): say a trigger phrase to type saved text, multi-line and any script; categories, language, enable/disable, dates, search, CSV import with preview and export. **Grouped sidebar**: Main (Dashboard, Dictation, History), Personalisation (Personal Dictionary, Snippets, Text Cleanup "Soon"), System (AI & Models, Settings). The Dictionary tab moved out of Settings into the sidebar.
- 2026-11-22, Stage 2: **Personal dictionary** (Settings ▸ Dictionary): exact whole-word replacements after Whisper plus spelling hints to Whisper, per-entry language/category/enabled/description, search and filters, conflict warnings, CSV import with preview, CSV export, sample template. Stored only on this Mac (`dictionary.json`, 0600). Also in the main window's sidebar.
- 2026-11-22, Stage 1: start/stop recording sounds (macOS system sounds, toggles, volume); microphone picker with fallback to the system default; "can't hear you" / "no signal" / "mic stopped" warnings while recording; recording limit setting (default **20 min**, was a fixed 30) with warnings at 1 min and a 10 s countdown; Settings ▸ Recording with a 5-second microphone test.
- 2026-11-22: Whisper gets "EsyType" as a vocabulary hint, so the app's name is no longer written "EZ type" (verified on all 4 models, and live through the microphone).
- 2026-11-22, Phase 10 (GitHub beta, not yet published): README, `Scripts/make-dmg.sh`, About ▸ Acknowledgements with bundled licence texts, version shown as "0.1.0 · Beta".
- 2026-11-22, Phase 9: speech model unloads after 10 idle minutes or under memory pressure. Intel Macs decode on the CPU with all physical cores. `Scripts/privacy-check.sh`. Benchmarks for short clips, CPU-only, thread counts, 30-minute audio and unload memory.

### Fixed
- 2026-11-22, Stage 3: VoiceOver read every badge ("Beta", "Soon") as "Preview, not real data".
- 2026-11-22, Stage 2: the Settings window was titled "Untitled" and, with 8 tabs, hid About behind a chevron; it's now titled by tab and 660 pt wide.
- 2026-11-22, Stage 1: a near-silent recording made Whisper invent text (and take 8 s); recordings without speech are no longer transcribed. The "EsyType" spelling hint made Whisper drop full stops; it's now a punctuated sentence. The log named the default mic "CADefaultDeviceAggregate"; it now names the real device.
- 2026-11-22, real-Mac end-to-end test (`Documentation/REAL_MAC_END_TO_END_TEST_REPORT.md`): **crash when quitting with a model loaded** (whisper.cpp's Metal cleanup at exit; the model is now freed first). Consecutive dictations no longer stick together (a space is added when the text before the cursor doesn't end in one). The log now says why text was copied instead of typed, and gives the AX error when focus can't be read.
- 2026-11-22: EsyType had no Dock icon or menu bar even with its window open, and ⌘C/⌘V/⌘A didn't work in its own text fields (no Edit menu). It now shows in the Dock and has EsyType/Edit/Window menus while a window is open, and goes back to menu-bar-only when the last window closes.
- 2026-11-22: macOS permissions reset after every rebuild (ad-hoc signatures change each build). Local builds are now signed with a self-signed **EsyType Dev** certificate in the developer's login keychain, which `build-app.sh` uses automatically when present, so permissions persist. Allow… for Input Monitoring now also tries a keyboard listener, because the request alone didn't add EsyType to the list on macOS 26. Public DMGs built elsewhere stay ad-hoc until a Developer ID exists.
- 2026-11-22, quality audit (`Documentation/FINAL_QUALITY_AUDIT.md`): **crash when stopping a dictation** (audio tap removed before the engine stopped). Recording now continues across input-device changes (e.g. Bluetooth headphones). Privacy-safe diagnostic logging. Shortcuts re-register only when changed, and conflicts are shown. Accurate microphone wording. `ARCHITECTURE.md`, `PRD.md`, `LICENCES.md` and `TESTING.md` corrected to match the code.
- 2026-11-22: holding Right ⌥ did nothing if Input Monitoring was allowed while another app was in front; the listener now retries every 2 s (in source; ships with the next install).
- 2026-11-22: dictation silently did nothing when permissions were missing (they reset whenever the app's signature changes). Home now lists missing permissions with Allow buttons, and the first dictation asks for the microphone. `build-app.sh` accepts a self-signed identity (`ESYTYPE_SIGN_IDENTITY`) so permissions survive rebuilds.
- 2026-11-22: opening EsyType (Spotlight, Finder) showed nothing when it was already running or after onboarding, since it's a menu-bar app and the icon can sit behind the notch. It now opens the main window; at login it still starts quietly. A second copy hands over to the running one instead of competing for the shortcuts.
- 2026-11-22: warning and success text were unreadable in light mode (1.4:1 and 2.1:1 contrast); now ≥ 5:1.
- 2026-11-22, Phase 7: dictation history (search, copy, delete, clear all, retention, optional source app), saved before pasting so nothing is lost. Working Settings: open at login, push-to-talk key and hands-free shortcut choices, model, language, translate to English, English filler removal, history options. Text cleanup removes Whisper markers.
- 2026-11-22, Phase 6: dictation now types into the app you're in (clipboard borrowed for ⌘V, then put back exactly). Falls back to copying when Accessibility is off, you switched apps, nothing has focus, or the field is a password field. Paste Last Transcript (menu, ⌃⌘V), kept in memory only. Layout-aware ⌘V.
- 2026-11-22, Phase 5: dictation works end to end, ending on the clipboard. Hold Right ⌥ (needs Input Monitoring) or press ⌃⌥Space for hands-free, Esc cancels. New `AudioRecorder` (16 kHz, in memory only), `DictationMachine` (tested shortcut rules), `Hotkeys`, `DictationController`; the overlay shows live levels. whisper.framework is now embedded in the app.

### Fixed
- 2026-11-22: audio conversion lost 7–15 % of samples when the microphone delivered buffers over 4,096 frames (found by the new converter test before release).
- 2026-11-22, Phase 4 (English): whisper.cpp b5454 linked through a pinned SwiftPM binary target. New `WhisperEngine` module with the `WhisperCppEngine` actor (load a model, transcribe 16 kHz audio, detect the language; all whisper.cpp output silenced). First real model downloads and a real-network resume. Benchmarks for all 4 models on the M4. Hindi/Marathi testing waits for clips.
- 2026-11-22, Phase 3: real model downloads. `ModelStore` downloads from the pinned Hugging Face revision with progress, cancel, resume (HTTP Range), retries, a duplicate guard and a disk check, then verifies exact size and SHA-256 before an atomic install into `~/Library/Application Support/EsyType/Models/`. New Models page (download, cancel, remove with confirmation). The onboarding download step is now real. 11 new tests (22 in total).
- 2026-11-22, Phase 2: `HardwareDetector`, `DiskSpace` and `Recommender` in EsyTypeCore with 8 new tests (11 in total). Onboarding now shows this Mac's real hardware and the recommended model with its reason, warnings and any disk shortfall. The download is still simulated (Phase 3).
- 2026-11-22, Phase 1: first runnable preview build (0.1.0). Universal app bundle via `Scripts/build-app.sh`. EsyAI design system with bundled Barlow and Instrument Serif fonts, and Liquid Glass with fallbacks. Menu-bar menu, 7-step onboarding with live permission status, main window and Settings shells, a recording overlay with 6 states and simulated levels, a provisional app icon, and `LevelMeter` with unit tests. Model, dictation and history features are shown as labelled previews.
- 2026-11-22: competitor research for hotkey and insertion approaches (internal notes, not published). ADR-5 and ADR-6 updated.
- 2026-11-22: Phase 0 research and planning documents (PRD, architecture, model registry, licences, testing strategy, research reports, UI design proposal). No application code yet.
